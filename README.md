# OpenCV Demo

A showcase of OpenCV's Python library, using its methods:
- find all orb features points in the image
- find all sift features points in the image
- find canny edges on images
- transfer to grayscale
- convert image to hsv
- reflect the image along the right border
- reflect the image along the lower border
- rotate the image by 45 degrees
- rotate the image by 30 degrees around the specified point
- move the image up to 10 pixels to the right
- change the image brightness
- change image contrast
- make a gamma transform
- make a histogram acquisition
- change the white balance, make a more "warm" picture
- change the white balance, make a more "cool" picture
- change the color palette based on a given template
- make binarization of the image
- find contours in a binarized image
- nati contours on the image by applying filters (Sobel or Laplacian)
- make the image blur
- make image filtering using a Fourier transform, leave only
fast frequencies
- filter the image using a Fourier transform, leaving only
slow frequencies
- apply an erosion operation to the image
- apply the dilation operation to the image
